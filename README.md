# portfolio

Personal portfolio site for **Epameinondas Papamichail** — front-end developer.

**Live:** https://nwntaspap.github.io/portfolio/

## Stack

Plain HTML and CSS. No framework, no build step, no dependencies — clone it and open `index.html`.

- `index.html` — hero, services, projects and FAQ sections
- `style.css` — all styling, driven by custom properties in `:root`
- `images/` — photo, illustrations and icons

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension
(port `5501`).
